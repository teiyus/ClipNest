# ClipNest

Local game clipper for Windows 10/11. Keeps the last moments of your game in memory and saves them with one key (F9). No account, no telemetry, clips stay on your PC.

## Download

**[Latest version → Releases](https://github.com/teiyus/ClipNest/releases/latest)**

Download `ClipNest-Setup-<version>.exe` and run it. No admin rights needed. Installed versions update themselves.
